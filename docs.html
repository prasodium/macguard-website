Docs

MacGuard watches your charger while armed. If it is unplugged, it sounds an alarm, requests a screen lock, looks up the location and emails you. Needs macOS 13+ on Apple Silicon.

Install

  1. Download MacGuard-0.2.0.dmg, open it and drag MacGuard to Applications.
  2. Right-click the app, choose Open, then Open again. It is not notarized yet.
  3. If macOS says it is damaged, run xattr -dr com.apple.quarantine /Applications/MacGuard.app once.

Or build it yourself: scripts/build_app.sh release in the repository. Allow Location when asked, and set Lock Screen → Require password to Immediately.

Set up email

Optional; the alarm and screen lock work without it. It takes about ten minutes. Open Settings → Email (the gear icon) in MacGuard.

1. Brevo account and sender

  1. Sign up for a free account at brevo.com and confirm the email Brevo sends you.
  2. In Brevo open Senders, Domains & Dedicated IPs → Senders and press Add a sender. Enter a name and the address alerts should come from.
  3. Open the verification email Brevo sends to that address and confirm it. Wait until the sender shows Verified.

2. API key

  1. In MacGuard press Get a key…. Brevo opens at SMTP & API → API Keys.
  2. Press Generate a new API key, name it MacGuard and copy it. Brevo shows it only once. Use an API key (starts with xkeysib-), not an SMTP password.
  3. Paste it into API key, type the verified sender into Sender exactly as in Brevo, and press Save. The key is stored only in your Keychain.

3. Alert address and test

  1. Under Gmail for alerts enter the address that should get alerts and press Send code.
  2. Type the 6-digit code and press Verify. The code lasts 15 minutes and allows 5 tries.
  3. Press Send test email, then check the inbox and spam. "Accepted by Brevo" means Brevo took it; delivery is not confirmed.

Alerts go only to a verified address.

Email delay (optional)

If you get too many emails, open Settings → Email → Email delay and set Wait between emails to 1, 2, 5, 10, 15, 30 or 60 minutes. The default is no delay.

RuleWhat happens
First alertSent immediately.
Later alertsHeld until the delay ends, then sent automatically. Nothing is lost, even if you quit the app.
Location updatesOnly the newest one for an incident is sent.
Test email, verification codeNever delayed.

A second, separate theft event during the delay also waits, so its alert can be late by up to the delay you set.

If email fails

MessageFix
Brevo rejected the keyGenerate a new API key and save it again.
Check that the sender address is verifiedFinish step 1 and copy the sender exactly.
Your Brevo plan cannot send more emailCheck Brevo for a daily limit or an account activation notice.
Send code is greyed outSave the key first and include the @ in the address.

Brevo may hold new accounts for a manual check, and may refuse free-mail senders such as @gmail.com unless the domain is authenticated. If sending still fails, use a sender on a domain you own.

Use it

Do thisResult
Plug in, press ArmProtection is on. Closing the window is fine; it keeps running in the menu bar.
Unplug the chargerAlarm, screen lock, location lookup and email, together.
Plug it back inThe alarm stops. Unplugging again starts a new alarm.
Stop Alarm or DisarmAsks for Touch ID or your Mac password.

Limits

MacGuard is a deterrent. It cannot stop a shutdown, a force-quit, or removal of all power.
  • Nothing happens while the Mac is off or asleep, or before you log in.
  • The alarm may be inaudible if the speakers are muted.
  • The lock needs a private macOS call; MacGuard says "Locked" only when macOS confirms it.
  • Location is an estimate and needs permission and internet.
  • You must arm while the charger is connected.

Beta: not yet tested on real hardware are many unplug cycles, a real email through Brevo, the location prompt, sleep and wake. See TESTING.md.

Security and privacy

  • No MacGuard server, account or tracking. Data stays on your Mac.
  • Your Brevo key lives in the Keychain. If the Mac is lost, delete the key in Brevo.
  • Only the alert emails leave your Mac, through your Brevo account.
  • MacGuard never sees your password or Apple ID.

Find My

Turn on Find My Mac in System Settings, then use icloud.com/find to see the Mac or mark it as Lost. If it was stolen, call the police and do not confront anyone.

Troubleshooting

ProblemFix
Can't armPlug in the charger and check the Charger tile.
No locationAllow MacGuard in Location Services, then run Test Location.
Email fails"Rejected the key": save a new key. "Sender": verify it in Brevo. Check spam.
Lock not confirmedSet Lock Screen to require the password immediately.

Uninstall

Disarm, then run scripts/uninstall.sh from the repository. Delete the key in Brevo too.
